# Lammah (لمّاح)
### AI-Powered Data Analysis Platform

Built at the Kanz AI Hackathon 2026 by a team of 2. Awarded a Gold Certificate.

## The Problem
Many small business owners, students, and professionals have valuable data but struggle to get clear insights from it, because traditional analysis tools are complex and hiring data specialists is costly.

## The Solution
Lammah turns Excel and CSV files into clear, easy-to-understand reports that support data-driven decisions, with no technical background or data analysis experience required.

## Live Demo
https://lammah-smart-insights.base44.app/app

## How It Was Built
The platform was built with a no-code approach using Replit and generative AI, with prompt engineering to guide the AI toward accurate and useful reports.

## Recognition
Gold Certificate, Kanz AI Hackathon 2026 (organized by Kanz AI, in cooperation with the Ministry of Human Resources and Social Development). Evaluated by AI-assisted judging.


## Note
This repository documents the project and contains no source code, because the platform was built with a no-code approach.
